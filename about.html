About the Project

Predictive Analytics for Electric Vehicle Market Growth using Hybrid Machine Learning and Time-Series.

Problem Statement

Existing EV market forecasting systems mainly rely on traditional statistical models or standalone ML algorithms that fail to capture complex spatial-temporal relationships. This project develops a hybrid forecasting framework that is accurate, interpretable, and deployable.

Objectives

  1. Hybrid CNN-LSTM-Attention deep forecasting
  2. Robust preprocessing and feature engineering
  3. Explainable AI with SHAP / LIME
  4. Model comparison vs classical and ML baselines
  5. Web dashboard for interactive forecasts

Live demos
