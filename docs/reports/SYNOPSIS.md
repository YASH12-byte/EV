# Synopsis — Predictive Analytics for EV Market Growth using Hybrid ML and Time-Series

## Title
Predictive Analytics for Electric Vehicle Market Growth using Hybrid Machine Learning and Time-Series

## Aim
To design and implement a hybrid deep learning and time-series forecasting system that predicts EV market growth with high accuracy, interpretability, privacy preservation, and physical feasibility.

## Objectives
1. Build CNN-LSTM-Attention hybrid forecaster  
2. Apply robust preprocessing and feature engineering  
3. Integrate Explainable AI (SHAP/LIME/attention)  
4. Demonstrate Federated Learning across regions  
5. Enforce physics-informed battery/grid constraints  
6. Compare against classical and ML baselines  

## Scope
Multi-region monthly EV sales forecasting web platform for academic demonstration and decision-support prototyping.

## Technology Stack
Python, Flask, TensorFlow/Keras, scikit-learn, XGBoost/LightGBM/CatBoost, SHAP/LIME, Flower (FedAvg design), SQLite, HTML/CSS/JS, Chart.js, Plotly

## Expected Outcome
A working end-to-end system with research documentation, trained/compared models, REST APIs, animated authentication UI, and analytics dashboard suitable for BE final-year submission and viva.
